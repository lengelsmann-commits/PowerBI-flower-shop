# Jardin de Charlotte — Power BI Analysis

University project focused on data analysis and interactive dashboard development using Power BI.

## Project

The project involved analysing a large dataset related to Jardin de Charlotte and developing interactive Power BI dashboards to explore the data and present key insights.

## Technologies

- Power BI
- Data Analysis
- Data Visualisation

## Dashboard

The project includes several interactive Power BI pages covering different aspects of the dataset.

## Project File

The original Power BI project is available in the `.pbix` file.

> Note: The original dataset used for this project is no longer available, so the project cannot be fully reproduced from the repository.
